# GenLayer Builder

Notes from the GenLayer builder onboarding.

## What this is

A small public repository used while going through the GenLayer Portal developer flow: connecting a wallet, linking GitHub, adding the Bradbury testnet, and deploying a first intelligent contract.

## Why intelligent contracts are interesting

A normal smart contract can only see what is already on chain. GenLayer contracts are written in Python and can read live data from the web, then reach consensus on the result. That means the contract can make a judgement call itself instead of trusting an oracle.
