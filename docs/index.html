GenLayer 合约证据台

三个部署在 GenLayer Studio 网络上的智能合约。页面不存数据，每次打开或刷新，直接把链上只读方法的结果读出来。

正在连接 Studio 网络 已复制地址

共识用在哪

存储与权限

第一个合约只存状态，写入前检查调用者是不是所有者。确定性逻辑，所有节点算出来必须一样。

容差而不是相等

第二个合约从外部接口取价格。不同节点同一秒拿到的数字不会完全一样，所以验证者比的是 0.5% 区间，不是字面相等。

判断也要有边界

第三个合约让模型读网页做判断。结果只能落在 PASS、FAIL、INSUFFICIENT 三个值里，开放式回答永远达不成一致。

怎么验证

打开这个页面，点一次刷新，三张卡片里的数字会直接来自 Studio 网络的读取调用。合约地址可以在仓库的 README 里对上，源码在 contracts 目录。

合约源码与部署记录在 github.com/mybitst/genlayer-builder。网络 GenLayer Studio，chainId 61999。
